## 🌟 Overview

The **Student Management System** is a robust Command-Line Interface (CLI) application built entirely in Python. It is designed for educators and administrators to effortlessly maintain, track, and update student performance data. The system automatically calculates academic grades and persists data locally, ensuring you never lose your records!

## ✨ Key Features

- **➕ Add Student**: Seamlessly onboard new students with their ID, Name, and Marks. The system automatically calculates their grade (`A+`, `A`, `B+`, `B`, `C`, or `Fail`).
- **📋 Display Records**: View all student details in a neatly formatted, easy-to-read list.
- **🔍 Search & Retrieve**: Quickly locate any student's data using their unique ID.
- **✏️ Update Information**: Easily modify a student's marks and let the system instantly recalculate their grade.
- **🗑️ Delete Student**: Safely remove student records from the database when needed.
- **🏆 View Topper**: Instantly identify the highest-performing student in the class.
- **📊 Analytics & Statistics**: Gain valuable insights including total student count, highest mark, lowest mark, and average performance.
- **💾 Persistent Storage**: Save all your data locally into `students.txt` so records are preserved across sessions.

## 🚀 Getting Started

Follow these simple steps to run the application locally on your machine.

### Prerequisites
Make sure you have Python installed. If not, download it from [Python's official website](https://www.python.org/downloads/).

### Installation & Execution
1. **Clone the repository:**
   ```bash
   git clone https://github.com/santhoshkumar7507/Student-Management-System-.git
   cd Student-Management-System-
   ```

2. **Run the application:**
   ```bash
   python student_management.py
   ```

3. **Navigate the Menu:**
   Use the interactive numbers (1-9) to perform operations on the student database.
